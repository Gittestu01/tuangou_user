# 团购团批微信小程序

## 项目概述

这是一个基于微信小程序的社区团购与分销系统，主要服务普通团员和团长，通过微信小程序实现社区团购与分销机制。目标是让用户轻松浏览附近开团商品、快速参团购买，并支持团长开团、分佣、推广。

## 核心功能

### 用户端功能
- **首页浏览**：搜索商品、定位服务、Banner轮播、今日开团列表、附近团购推荐
- **商品详情**：商品展示、团长信息、参团功能、分享推广
- **订单管理**：确认订单、支付结算、订单跟踪、收货确认
- **购物车**：商品管理、批量结算、积分抵扣
- **个人中心**：用户信息、订单管理、收藏中心、地址管理

### 团长端功能
- **团长中心**：数据总览、开团管理、订单管理、业绩查看
- **开团功能**：商品选择、价格设置、团购管理、分享推广
- **订单处理**：订单确认、发货管理、提货核销、客户服务
- **业绩管理**：收益统计、提现申请、推广奖励

### 营销功能
- **推广中心**：邀请好友、推广码生成、业绩统计
- **积分系统**：积分获取、积分抵扣、积分兑换
- **分销机制**：团长申请、分佣计算、业绩提现

## 技术架构

### 前端技术栈
- **框架**：微信小程序原生开发
- **样式**：WXSS + 响应式设计
- **状态管理**：全局数据管理
- **组件化**：自定义组件开发

## 页面功能说明

### 1. 首页 (home)
- 顶部搜索栏（商品关键词搜索）
- 定位信息显示与切换
- Banner轮播广告位
- 今日开团列表（商品卡片：图、价、倒计时、团长信息）
- 附近团购推荐（基于定位推荐团长开团）

### 2. 商品详情页 (product-detail)
- 图片/视频展示区
- 商品名、团购价、划线价、库存、截止时间
- 团长信息（头像 + 地址 + 地图）
- 商品图文详情
- 操作按钮区：「立即参团」「收藏」「分享」

### 3. 确认订单页 (order-confirm)
- 商品列表（图片、数量、价格）
- 收货方式（默认团长地址）
- 积分抵扣信息（自动显示抵扣金额）
- 支付方式选择（微信/支付宝）
- 同意团购协议复选框
- 「确认支付」按钮

### 4. 支付成功页 (payment-success)
- 支付金额、积分抵扣明细
- 提示"请等待团长确认收货"
- 按钮：「查看订单」「回首页」

### 5. 营销中心 (marketing)
- 我要成为团长（申请入口）
- 今日业绩/累计业绩显示
- 可提现金额/积分余额
- 推广人数统计（客户数/团长数）
- 推广码二维码生成
- 邀请好友加入/成为团长

### 6. 购物车 (cart)
- 列表展示当前选购商品
- 商品卡片信息：图、名、数量、团购价
- 可勾选批量结算
- 积分抵扣提示
- 自动移除已结束团购
- 「一键结算」按钮

### 7. 我的页面 (profile)
- 用户信息（头像、昵称、等级）
- 积分余额/提现金额
- 订单管理：待付款、待发货、待收货、已完成、退换货
- 推广中心（推广码、邀请链接）
- 收藏中心（收藏商品、收藏团长）
- 地址管理（定位 + 常驻地址）

### 8. 团长中心 (captain-center)
- 团长数据总览：今日团数、业绩、订单数
- 新开团按钮
- 开团流程：选择商品、设置价格、数量、截止时间
- 订单管理：团购进度列表、收货确认按钮
- 业绩页：累计业绩、提成金额、积分明细

## 开发说明

### 环境要求
- 微信开发者工具
- Node.js (可选，用于构建工具)

### 开发步骤
1. 克隆项目到本地
2. 使用微信开发者工具打开项目
3. 配置小程序AppID
4. 开始开发和调试

### 配置说明
- `app.json`：全局配置，包含页面路由、底部导航、窗口样式等
- `app.js`：全局逻辑，包含用户信息管理、购物车管理等
- `app.wxss`：全局样式，包含通用样式类

### 数据管理
- 使用全局数据管理用户信息、购物车等
- 本地存储用于数据持久化
- 模拟API调用，实际开发时需要对接后端接口
